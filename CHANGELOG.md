# Changelog

## 0.1.0

The first date. 💐

- Opens `.md` and `.markdown` files in ReadMeMaybe automatically (toggle with **ReadMeMaybe: Toggle Auto-Open for Markdown Files**).
- Read mode with GitHub-flavored Markdown, alerts, task lists, footnotes, emoji, front matter, syntax highlighting and sanitized HTML.
- Mermaid diagrams, themed and lazy-loaded, with a view-larger lightbox and a friendly error card.
- Edit mode: click any block to edit its Markdown in place, with a format bar, shortcuts and list continuation.
- Find in document, outline drawer, copy buttons, and a collapsible toolbar.
- Themes: Auto, Light, Dark, Sepia, Ocean; sans/serif fonts; size and width controls.
- Live updates when the file changes on disk or in another editor.
